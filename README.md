# مكسبي — Maksabi

مساعد شخصي ذكي للعمل والمال والحياة، مع سجل دخل ومصاريف، تتبع عمل وميلات، أهداف، ومساعد AI قادر على اقتراح إجراءات داخل التطبيق بعد فهم اللغة الطبيعية.

## V6 intelligence work

فرع `maksabi-v6-intelligence` يركز على جعل المساعد أقل اعتمادًا على النماذج الجامدة وأكثر فهمًا للسياق:

- فهم عدة حقائق وإجراءات من رسالة واحدة.
- استخدام تاريخ محلي واضح بدل التخمين في «اليوم/أمس».
- حساب ملخص اليوم من البيانات المسجلة وإرساله للمساعد كسياق مشتق.
- الحفاظ على سياق التصحيحات والمتابعات القصيرة.
- منع الأسئلة عن معلومات موجودة بالفعل.
- التعامل الطبيعي مع تأكيدات مثل «اي ضيفها» و«تمام نفذ».
- الفصل بين الحقائق المسجلة والتقديرات.
- الاستمرار كمساعد عام عندما يكون السؤال خارج المال.
